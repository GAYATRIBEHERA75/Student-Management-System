# Student Management System

A menu-driven Student Management System developed using Java and Object-Oriented Programming principles.

## Features

* Add Student
* View Students
* Search Student by ID
* Delete Student
* Menu-driven console application

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* Scanner Class

## Project Structure

Student-Management-System
├── Student.java
├── StudentManagement.java
└── README.md

## How to Run

Compile:
javac Student.java StudentManagement.java

Run:
java StudentManagement
